This documentation set walks through everything needed to install Python and get it running on your machine.

1. `Introduction.md`

## Conclusion

Installing Python is a quick process on any major operating system: download the installer from the official source, run it (remembering to add Python to your PATH on Windows), and verify the install with a simple version check in your terminal. With Python and pip installed, you're ready to start writing scripts, installing packages, and building projects.

If you run into issues along the way, the Troubleshooting section in `Installation.md` and the `FAQ.md` file cover the most common problems and their fixes.
