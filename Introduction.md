# Introduction

## What is Python?

Python is a high-level, general-purpose programming language known for its readable syntax and broad ecosystem of libraries. It is widely used for web development, data analysis, automation, scripting, artificial intelligence, and scientific computing.

## Why Install Python?

To write and run Python programs on your computer, you need the Python interpreter installed locally. Installing Python gives you access to:

- The **Python interpreter**, which executes your code
- **pip**, the package manager used to install third-party libraries
- **IDLE**, a basic built-in code editor
- Command-line tools for running scripts and managing environments

## Who This Guide Is For

This documentation walks through installing Python on Windows, macOS, and Linux. It is intended for beginners setting up Python for the first time, as well as anyone who needs a refresher on the installation and verification process.
