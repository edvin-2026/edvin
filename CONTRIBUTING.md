# Contributing

Thank you for contributing to this Python student project!

## 1. How to Report an Issue

If you find a problem:

1. Open the project's issue section.
2. Describe the problem clearly.
3. Explain the steps to reproduce the problem.
4. Include any useful error messages.

## 2. How to Suggest a Feature

To suggest a new feature:

1. Open the project's issue section.
2. Describe the feature you would like to add.
3. Explain why the feature would be useful.
4. Keep the suggestion clear and simple.

## 3. How to Create a Branch

Create a separate branch for your changes.

Use a clear branch name that describes your work.

Example:

```text
feature-add-new-calculation
```

## 4. How to Make Changes

1. Create a branch for your work.
2. Make the required changes.
3. Keep your changes focused on one task.
4. Write clear and readable code.
5. Save your changes.

## 5. How to Test Changes

Before submitting your changes:

1. Run the Python program.
2. Check that the changes work as expected.
3. Test important inputs and outputs.
4. Make sure your changes do not cause existing features to stop working.

## 6. How to Create a Pull Request

After testing your changes:

1. Create a pull request.
2. Give the pull request a clear title.
3. Describe what you changed.
4. Explain how you tested the changes.
5. Submit the pull request for review.

## 7. Basic Coding Guidelines

- Use clear and meaningful names for variables and functions.
- Keep the code simple and easy to understand.
- Use consistent indentation.
- Add comments when they help explain the code.
- Avoid unnecessary changes.
- Keep each change focused on its purpose.

Thank you for helping improve the project!
