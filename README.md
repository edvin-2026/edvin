# Student Grade Calculator

## Description

**Student Grade Calculator** is a beginner Python project designed to calculate a student's grade based on their marks.

## Features

- Calculate a student's grade.
- Simple and beginner-friendly Python project.

## Requirements

- Python 3 or later

## Installation

1. Install Python 3 or later.
2. Download or clone the project.
3. Open the project folder in your terminal or command prompt.

## Usage

Run the Python program from the project folder:

```bash
python main.py
```

Enter the required marks when prompted to calculate the student's grade.

## Example

```text
Enter marks: 85
Grade: A
```

> **Note:** The grading criteria can be added or changed according to the project's requirements.
